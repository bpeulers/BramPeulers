De Hypotheker —Mortgage file

ClientDe Hypotheker
RoleVisual designer
Period2020
TypePortals & dashboards

Commissioned by Yellowtail Conclusion, I worked on a mortgage file environment for customers of De Hypotheker. The previous version was outdated and not responsive. A nice bonus was that De Hypotheker was rolling out a new visual identity at the time, so we were able to use and develop that new style in the new environment.

Process

The goals of this project were to modernise the mortgage file and to guide the customer through the application process for a new mortgage. Together with a consultant and another UX designer from Yellowtail, we organised co-creation sessions in which stakeholders could think along about the design and we could present the prototypes.

1 / 2

UX design goals

These were the main UX goals:

Goal 1: Improve the user experience

  • Offer ease of use
  • Clear steps in the process
  • Provide guidance at the right moments
  • Reduce content

Goal 2: Responsive design

  • Large buttons
  • Clear steps
  • Keep it simple

Goal 3: Easy access to an adviser

  • Be able to get in touch anytime, anywhere
1 / 3

The result

For this concept we used De Hypotheker’s new brand identity. We started by designing a low-fidelity concept (interaction design). In one of the workshops we had the group of stakeholders think along about these concepts. We then developed the final concept into a high-fidelity prototype, to be built later and tested with the target group. An important requirement was that users had to be guided through the mortgage process with clear steps.
